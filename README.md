# Quest 3 单目投屏

这是一个面向 Windows 的简易 Quest 3 有线投屏启动器。它通过官方 scrcpy 4.1 运行组件工作，只选择 USB 设备，不会启用无线 ADB。

## 使用方法

1. 在 Quest 3 中开启开发者模式和 USB 调试。
2. 使用支持数据传输的 USB 线连接电脑。
3. 第一次连接时，在头显里勾选“始终允许”并确认 USB 调试。
4. 运行 `Quest3SingleEye.exe`。
5. 选择左眼或右眼，设置旋转角度，然后点击“开始投屏”。
6. 点击“全屏 / 窗口”切换显示模式，也可以在投屏窗口直接按 `F11`。

左右眼切换或应用新的旋转角度时，视频流会短暂重新连接。旋转角度会分别为左右眼自动保存。

## 默认设置

- USB 有线设备：强制使用
- 音频：关闭
- 控制：关闭，仅观看
- 视频：H.264、最高 60 FPS、20 Mbps
- 默认旋转：左眼顺时针 10°，右眼逆时针 10°，可在界面中分别调整

如果画面向相反方向倾斜，请把旋转角度调整为负数。

Quest 处于休眠或息屏状态时，投屏窗口可能显示黑画面；戴上头显并唤醒后再开始投屏即可。

## 目录结构

- `Quest3SingleEye.exe`：启动器
- `scrcpy/`：官方 scrcpy 4.1 Windows 运行组件
- `THIRD_PARTY_NOTICES.md`：第三方软件及许可证说明
- `scrcpy-master/`：用户提供的官方源码副本，仅用于查阅和后续开发

## 构建

在 PowerShell 中运行：

```powershell
.\build.ps1
```

生成文件位于 `release/`。
